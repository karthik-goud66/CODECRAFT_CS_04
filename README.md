# CODECRAFT_CS_04
Developed a Python-based keyboard event logging demonstration to understand keystroke capture and file handling in a controlled environment, with a focus on ethical cybersecurity practices and user privacy.
# ⌨️ Simple Keylogger — Ethical Demonstration

## 📌 Project Overview
This project demonstrates keyboard event logging in a controlled Python environment. It introduces the concepts of keyboard input events, event handling, and writing test data to a file.

This project was developed as part of **Task 04 – Cyber Security Internship at CodeCraft Infotech**.

## 🎯 Objectives
- Understand keyboard event handling.
- Learn basic file operations in Python.
- Explore how keystroke logging works in a controlled environment.
- Understand the ethical and privacy risks associated with keyloggers.

## 🛠️ Technologies Used
- Python 3
- Tkinter
- File handling

## ✨ Features
- Captures keyboard input within the application's own test window.
- Saves demonstration input to a local text file.
- Provides a controlled environment for learning.
- Does not monitor other applications or run secretly in the background.

## ▶️ How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the program:

```bash
python keylogger_demo.py
```

5. Use the application's test window to enter sample text.
6. Review the demonstration log file generated by the program.

## 🔒 Ethical Considerations
- Obtain explicit permission before conducting any keyboard-monitoring experiment.
- Never collect passwords, banking details, or other sensitive information.
- Do not monitor another person's device without authorization.
- Keep demonstration logs local and delete them when they are no longer needed.

## 📚 Learning Outcomes
- Understood keyboard event handling.
- Practiced Python file handling.
- Learned about keylogger-related security risks.
- Recognized the importance of consent and privacy.
